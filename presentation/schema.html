三、输出 Schema（强制 JSON）

{
  "p_call":     0..1，跟注为正确决策的主观概率（主指标来源）
  "action":     "call"|"fold"，与 p_call≥0.5 一致
  "cues":       [{t 秒, who, type, observed 客观事实, direction 强/弱/中性, weight}]
                ← 每条可核验，禁情绪词；幻觉率的靶子
  "rationale":  ≤150 字
  "recognized": 是否认出这手牌/选手（污染自报，标 true 的题单独统计剔除）
}

四、计分（纯程序，零模型参与主分）

主分 EV(bb) ＝ p_call × EV(call)，EV(call)=(胜率×终池−跟注额)/bb
口径 avg@3（每题 3 次取均值，评可靠性不评运气上限）；排名唯一依据
读人增益 ＝ EV(L1) − EV(L0)　头条数字：多"看见"一层，多赚/少亏多少
附录诊断（不参与排名）回答什么
Brier 分概率报得准不准（抓"瞎自信"）
与牌手一致率和当事职业牌手做了同样决定吗
幻觉率它说"看到手在抖"——画面里真的有吗（judge 三档 + 人工抽检）
trial 稳定性同题 3 次答案漂不漂

五、真实 Case 演示：F1（$94,475 大池）

牌局：主角 Ad Qc，对手河牌全下 $30,350，所需胜率 32.1%
真值：对手 Ks Tc 河牌成葫芦，主角胜率 0% → 正确答案 fold（correct_call=False）
职业牌手实际：call，输掉 $94,475（当日争议手）
Claude · L0（蒙眼层）输出：
{
 "p_call": 0.32,
 "action": "fold",
 "cues": [],
 "rationale": "仅凭牌理，无行为线索。河牌成双K，我的A高无听牌，仅诈唬才能赢。对手连续三条街下注且河牌全下，代表范围偏两对以上。所需胜率32.1%，我方只赢纯诈唬，概率估计低于此线。",
 "recognized": false
}
打分：EV(call)=−607 bb；soft 得分 = 0.32 × (−607) = −194.2 bb；Brier=(0.32−0)²=0.102
看点：只凭牌理，模型判 fold 躲开了职业牌手踩中的大坑——L1 层它看了对手表演之后，会更坚定，还是被带偏？
